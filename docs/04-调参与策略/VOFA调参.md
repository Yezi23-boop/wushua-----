# VOFA 调参

## 适用场景

VOFA 更适合这些情况：

- 快速在线微调参数
- 观察某个改动对车体响应的即时影响
- 做短周期调试，不频繁翻菜单

比赛正式跑车时，通常不建议常开 VOFA。

## 当前命令分类

### 可进入配置并支持保存

- `A_KP`
- `A_KD`
- `SPEED_RUN`
- `SAVE`
- `LOAD`

这类命令的行为是：

1. 改 `gapp_config
2. 调 `control_apply_config()`
3. `SAVE` 后写入 EEPROM

### 仅作用于当前运行态

- `L_KP`
- `L_KI`
- `L_KD`
- `R_KP`
- `R_KI`
- `R_KD`
- `TEST_speed`
- `TEST_angle`
- `MOTOR`
- `ERR`
- `START`
- `STOP`
- `FUYA`

这类命令主要用于调试和测试，不保证掉电保留。

## 建议使用方式

推荐小步调参流程：

1. 先只改一个参数
2. 观察车辆表现
3. 如果有效，再决定是否 `SAVE`
4. 如果效果不好，先恢复再测，不要连续叠加多个临时改动

## 常见误区

### 改了参数却没保存

这是最常见情况。  
只改不 `SAVE`，重启后会丢。

### 把运行型命令当成持久化命令

像左右速度环一类运行型命令，当前更偏向调试用途，不应假定一定会写入 EEPROM。

### 让 VOFA 长期开着

当前实现仍然带有文本解析和较多打印，适合调试，不适合比赛常开。
