# 参数与调参指南

## 参数分组

当前 EEPROM 配置参数可按五组理解：

### 起跑与负压

- `start_flag`
- `element_enable`
- `track_mode`
- `fuya_xili`
- `fuya_wall_percent`（当前固定负压策略下保留，不参与动态输出）
- `element_len`
- `element_seq[0..5]`

### 速度与转向误差

- `kp_Err`
- `kd_Err`
- `gyro_damp_Err`
- `speed_run`
- `limiting_Err`
- `kp2_Err`

### 角度与误差映射

- `kp_Angle`
- `kd_Angle`
- `gyro_feedback_scale`
- `limiting_Angle`
- `A_1`
- `B_1`
- `C_l`

### 圆环相关

菜单路径：`RING → SMALL/LARGE`，大小圆环各持一套独立参数：

- `SMALL`：小圆环参数组（`app.ring.small_profile`，含斜率与全部控制参数）
- `LARGE`：大圆环参数组（`app.ring.large_profile`，含斜率与全部控制参数）

每组下分三个子页：

- `ENTRY`：进/出环电感偏置增益、入环 yaw/里程阈值、出环里程与满圈角度阈值、环速
- `CTRL`：环内 ABC 权重与方向环 Kp/Kd/Kp2
- `DRIVE`：角速度环 Kp/Kd

### 飞坡相关

- `count_fly_speed`
- `count_fly_time_1`
- `count_fly_time_2`

## 推荐调参顺序

现场调车建议尽量按这条顺序走：

1. 先确认硬件状态正常
2. 再确认电感采样和误差 `Err` 合理
3. 再调转向环 `kp_Err / kd_Err / kp2_Err`
4. 再调角度环 `kp_Angle / kd_Angle`
5. 最后再推目标速度 `speed_run`

如果是特殊赛道元素，再单独处理：

- 圆环再动 `ring` 组
- 飞坡再动 `fly` 组
- 壁面或附着当前优先看固定输出参数 `fuya_xili`

## 菜单与 VOFA 的关系

菜单和 legacy VOFA 都是现场调试入口，但写入路径不同：

- 菜单：更适合现场离线调参和查看多页信息
- VOFA：更适合快速在线小步试验，当前 legacy 命令直接改运行态 PID 或测试变量

统一规则是：

- 会保存的参数应该先写入全局配置对象 `app`
- 然后通过 `control_apply_config()` 同步到运行控制器
- 执行 `SAVE` 后再写入 EEPROM

当前 legacy VOFA 的速度环 PID 命令不走完整 `app` 链路，掉电保存和长期复现仍应优先依赖菜单/EEPROM 配置。

## 保存与加载规则

### 参数立即生效

只要改的是已经接入统一配置链的参数，修改后会立即生效，不需要重启单片机。

### 掉电后保留

只有执行 `SAVE` 后，配置才会写进 EEPROM。  
如果只改不保存，当前上电周期有效，重启后会丢失。

### 重新加载

执行 `LOAD` 后，会：

1. 从 EEPROM 读出配置
2. 恢复到 `app`
3. 再同步到 PID

## 现场调车建议

- 每次只动少量参数，避免一次同时改多项
- 高速状态下优先保证误差和转向链稳定，再谈极限速度
- 如果某次调参明显变差，不要继续叠加试错，先回退到上一个稳定点
- 对于菜单和 VOFA，尽量只保留一个主用入口，减少“双边都在改”的混乱
- 特殊元素异常时先看状态显示：`expected_element`、圆环状态、圆桶状态和 `flat_fly`

## 元素顺序现场配置

元素编号固定为：`0` 空槽、`1` 左圆环、`2` 右圆环、`3` 大圆环左、`4` 大圆环右、`5` 圆桶、`6` 墙面、`7` 跷跷板/飞坡、`8` 双十字、`9` 单十字。

常用填法：

| 场景 | 菜单配置 |
| --- | --- |
| 默认流程 | `E1=1, E2=5, E3=7, E4=6` |
| 不跑跷跷板 | `E1=1, E2=5, E3=6` |
| 含大圆环左 | 把对应 `E` 改成 `3`，参数在 `RING→LARGE` 页调节 |
| 临时跳过某槽 | 把对应 `E` 改成 `0` |
| 右圆环 | 把对应 `E` 改成 `2`，复用圆环状态机反向执行 |

运行中改 `E1~E8` 不会立刻打断当前元素，当前元素完成后才按新序列进入下一项。序列里填 `7` 时会进入跷跷板阶段；需要跳过跷跷板时，把 `7` 从序列中删掉。

异常兜底规则：

- `LEN` 为 0 或大于 6 时，运行期进入空状态。
- 全 0 或有效长度内没有可执行元素时，运行期进入空状态。
- 槽位出现 6、99、负值等非法编号时，运行期跳过该槽位。
- 这些兜底只发生在赛道元素仲裁中，不会改写 `app.start.element_seq[]`，也不会自动写 EEPROM。
