# 参数与调参指南

## 参数分组

当前 EEPROM 配置参数可按五组理解：

### 起跑与负压

- `start_flag`
- `circle_flags`
- `track_mode`
- `fuya_xili`
- `fuya_wall_percent`（当前固定负压策略下保留，不参与动态输出）
- `element_len`
- `element_seq[0..5]`

### 速度与转向误差

- `kp_Err`
- `kd_Err`
- `gyro_damp_Err`
- `speed_run`
- `limiting_Err`
- `kp2_Err`

### 角度与误差映射

- `kp_Angle`
- `kd_Angle`
- `gyro_feedback_scale`
- `limiting_Angle`
- `A_1`
- `B_1`
- `C_l`

### 圆环相关

- `ring_entry_encoder`
- `pre_ring_Gyro_target`
- `pre_ring_Gyroz`
- `in_ring_Gyroz`
- `pre_out_ring_Gyro_target`
- `pre_out_ring_Gyroz`

### 飞坡相关

- `count_fly_speed`
- `count_fly_time_1`
- `count_fly_time_2`
- `fly_ramp_enable`

## 推荐调参顺序

现场调车建议尽量按这条顺序走：

1. 先确认硬件状态正常
2. 再确认电感采样和误差 `Err` 合理
3. 再调转向环 `kp_Err / kd_Err / kp2_Err`
4. 再调角度环 `kp_Angle / kd_Angle`
5. 最后再推目标速度 `speed_run`

如果是特殊赛道元素，再单独处理：

- 圆环再动 `ring` 组
- 飞坡再动 `fly` 组
- 壁面或附着当前优先看固定输出参数 `fuya_xili`

## 菜单与 VOFA 的关系

菜单和 VOFA 现在都应当理解为“改配置入口”，但职责略有区别：

- 菜单：更适合现场离线调参和查看多页信息
- VOFA：更适合快速在线小步改参

统一规则是：

- 会保存的参数应该先写入全局配置对象 `app`
- 然后通过 `control_apply_config()` 同步到运行控制器
- 执行 `SAVE` 后再写入 EEPROM

## 保存与加载规则

### 参数立即生效

只要改的是已经接入统一配置链的参数，修改后会立即生效，不需要重启单片机。

### 掉电后保留

只有执行 `SAVE` 后，配置才会写进 EEPROM。  
如果只改不保存，当前上电周期有效，重启后会丢失。

### 重新加载

执行 `LOAD` 后，会：

1. 从 EEPROM 读出配置
2. 恢复到 `app`
3. 再同步到 PID

## 现场调车建议

- 每次只动少量参数，避免一次同时改多项
- 高速状态下优先保证误差和转向链稳定，再谈极限速度
- 如果某次调参明显变差，不要继续叠加试错，先回退到上一个稳定点
- 对于菜单和 VOFA，尽量只保留一个主用入口，减少“双边都在改”的混乱
- 特殊元素异常时先看状态显示：`expected_element`、圆环状态、圆桶状态和 `flat_fly`

## 元素顺序现场配置

元素编号固定为：`0` 空槽、`1` 左圆环、`2` 右圆环预留、`3` 圆桶、`4` 墙面、`5` 跷跷板/飞坡。

常用填法：

| 场景 | 菜单配置 |
| --- | --- |
| 默认流程 | `LEN=4, E1=1, E2=3, E3=5, E4=4` |
| 不跑跷跷板 | `LEN=3, E1=1, E2=3, E3=4` |
| 临时跳过某槽 | 把对应 `E` 改成 `0` |
| 右环预留 | 填 `2` 会被当前程序跳过 |

运行中改 `LEN` 或 `E1~E6` 不会立刻打断当前元素，当前元素完成后才按新序列进入下一项。`fly_ramp_enable=0` 时，即使序列里填了 `5`，跷跷板也会被跳过。

异常兜底规则：

- `LEN` 为 0 或大于 6，会在 RAM 中回到默认序列。
- 全 0、全 2、或有效范围内没有可执行元素，会在 RAM 中回到默认序列。
- 槽位出现 6、99、负值等非法编号，会先在 RAM 中清为 0；如果因此没有可执行元素，再回到默认序列。
- RAM 兜底不会立即写 EEPROM，只有菜单执行 SAVE 后才持久化。
