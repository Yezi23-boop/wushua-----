# 已知问题与优化清单

这份清单只记录当前文档和源码中已经能看出的风险点，方便后续维护时按优先级处理。

## 当前已知问题

- 部分历史文档仍来自旧方案，阅读时应优先以 `整体运行流程.md`、模块说明和当前源码为准。
- `a_run_track_element` 已接入左/右圆环、圆桶、跷跷板和墙面串行仲裁；右圆环复用圆环状态机并反向控制。
- 跷跷板/飞坡 RECOVER 阶段依赖固定计数和电感阈值，换车速或换场地后需要重新验证。
- 负压当前在预启动阶段采用 EEPROM 固定值输出，`fuya_wall_percent` 和旧动态更新接口仅作为保留兼容项。
- 高频链路中仍有较多全局状态，现场调试方便，但维护时要注意中断与主循环共享访问。

## 优化方向

- 若右圆环现场表现不稳定，再补充独立入口特征或调参说明，避免左右方向阈值混淆。
- 给飞坡 RECOVER 阶段增加更明确的调参说明或菜单显示，方便现场判断是否处于限转向窗口。
- 若以后重新启用动态负压，需要先明确平地、墙面、圆桶和预启动阶段的优先级。
- 将关键状态显示集中到菜单或 VOFA 调试帧中，优先显示 `expected_element`、`flat_fly`、`stop` 和电感值。
- 持续清理历史命名和旧注释，让文档、菜单名和代码变量逐步统一。

## 维护建议

- 修改 5ms 主控链前，先更新或检查 `整体运行流程.md` 与 `a_run.md`。
- 修改特殊元素状态机前，先更新 `a_run_track_element.md` 和相关调参说明。
- 修改 EEPROM 字段时，同步更新 `参数与调参指南.md`、`EEPROM参数表.md` 和菜单/VOFA 文档。
