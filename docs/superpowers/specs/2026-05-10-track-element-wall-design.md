# 赛道元素墙面接入设计

## 背景

当前 `a_run_track_element.c` 的赛道元素链路为：

```text
左圆环 -> 圆桶 -> 左圆环
```

现场赛道实际顺序为：

```text
左圆环 -> 圆桶 -> 墙面 -> 左圆环
```

圆桶完成后如果立即重新开放左圆环识别，墙面或下墙过渡段的电感特征可能误命中左圆环入口，导致第二轮刚进入圆环流程就快速进入固定角速度阶段。

## 目标

- 在赛道元素仲裁中新增墙面元素。
- 圆桶完成后先进入墙面流程，墙面结束后再开放左圆环。
- 墙面识别不依赖 IMU，只使用 `ad1`、`ad2`、`ad3`、`ad4`。
- 保持 5ms 主控制链路内的实现轻量，避免新增复杂滤波或浮点计算。

## 状态链路

新增 `ELEMENT_WALL`，整体元素顺序为：

```text
ELEMENT_LEFT_RING
  -> 左圆环完成
ELEMENT_CYLINDER
  -> 圆桶完成
ELEMENT_WALL
  -> 墙面完成
ELEMENT_LEFT_RING
```

在 `ELEMENT_WALL` 期间，不调用 `circle_check_l(1)`，避免墙面阶段误触发圆环入口。

## 墙面识别信号

横向有效条件：

```text
ad1 > 40 && ad4 > 40
```

纵向高值条件：

```text
ad2 > 70 || ad3 > 70
```

墙面识别简化为横向有效与纵向高值同时成立，不再要求 5ms 差分。
该取舍优先保证圆桶后的墙面段能被识别到，再通过现场阈值调整误判风险。

## 墙面状态机

新增墙面内部状态：

```text
WALL_IDLE
WALL_WAIT_SIGNAL
WALL_TIMING
```

状态含义：

- `WALL_IDLE`：空闲态，复位计数和历史采样。
- `WALL_WAIT_SIGNAL`：等待 `ad1/ad4` 横向有效，同时 `ad2/ad3` 任一路超过高值阈值。
- `WALL_TIMING`：墙面强信号确认后开始计时。

`WALL_TIMING` 持续 1000ms 后，认为已经下墙到地面，墙面流程完成。

## 数据流

5ms 主控制链路中：

```text
read_AD()
  -> 更新 ad1/ad2/ad3/ad4
a_run_mode_update_track_element_gate()
  -> 根据 expected_element 推进左圆环、圆桶或墙面
gyro_integrals()
  -> 仅在圆环阶段更新 yaw/encoder
```

墙面状态机只读取当前电感值，不影响普通循迹的 `Err` 计算。

## 调试显示

现有菜单已经显示：

- `X`：当前元素。
- `C`：圆桶状态。
- `S`：圆环状态。
- `Yd/E/T`：圆环关键量。

实现时建议新增墙面状态读取接口，并在同一调试区域显示 `W`，方便确认墙面状态是否停在 `WAIT_SIGNAL` 或进入 `TIMING`。

## 风险与约束

- 简化后墙面只看强信号，误判风险高于完整波形识别；若误判，再提高 `WALL_AD_HIGH_THRESHOLD` 或加入连续命中计数。
- 墙面计时 1000ms 是初始值，若实际下墙时间更长，应调到 1200ms 或 1500ms。
- 该设计只改变元素仲裁顺序，不改变圆环内部角速度控制和圆桶强信号判断。

## 验证计划

1. Keil 构建确认 `0 Error(s), 0 Warning(s)`。
2. 静态检查状态链：
   - 左圆环完成后 `X` 从 1 变为 3。
   - 圆桶完成后 `X` 从 3 变为墙面编号。
   - 墙面完成后 `X` 回到 1。
3. 现场观察墙面波形：
   - 圆桶结束后进入 `WALL_WAIT_SIGNAL`。
   - 横向有效且 `ad2/ad3` 任一路超过高值后进入 `WALL_TIMING`。
   - 1000ms 后重新开放左圆环。
