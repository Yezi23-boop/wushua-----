# 运行与排障

## 上电前检查

- 电池电压正常，负压风扇和双电机接线牢靠。
- 四路电感接线与 `ADC.c` 中通道映射一致。
- P36 启动按键、P43 指示灯和 P32 下载/复位保护脚状态正常。
- 菜单中关键参数已确认，必要时先执行 `LOAD` 恢复 EEPROM 配置。

## 启动流程

1. 上电后等待初始化完成，IMU 会进行 gyro_z 零漂准备。
2. 通过菜单或 VOFA 检查 `ad1~ad4`、`Err`、速度和关键状态。
3. 按 P36 进入预启动，再次确认后经过约 1s 窗口进入运行态。
4. 运行态中主循环菜单刷新会暂停，核心控制由 5ms/10ms 中断链承担。

## 常见异常

| 现象 | 优先检查 |
| --- | --- |
| 按键后不跑 | P36 电平、启停状态是否到 2、`stop` 是否已锁定 |
| 一上电就保护 | 电池电压采样、四路电感是否全低、堵转保护计数 |
| 丢线误停车 | `ad1~ad4` 归一化是否过低、飞坡窗口是否应屏蔽丢线 |
| 转向慢半拍 | `read_AD()`、`gyro_z`、转向外环分频和角速度内环参数 |
| 跷跷板落地打滑 | `count_fly_speed`、RECOVER 阶梯提速和前段限转向 |
| 圆桶后误进圆环 | `expected_element`、圆桶完成条件和墙面计时 |
| 参数改了不生效 | 是否调用 `control_apply_config()`，是否只是改了 EEPROM 未同步 PID |

## 现场排查顺序

1. 先确认硬件输入：电感、电压、编码器、IMU。
2. 再看状态：`a_run_mode_get_start_state()`、`expected_element`、`flat_fly`、`stop`。
3. 再看控制量：`Err`、`PID.steer.output`、`PID.angle.output`、左右目标速度。
4. 最后再改参数，每次只改少量，并记录稳定版本。

## 实时性注意

- 不要在 `run_time_1()` 中加入串口打印、屏幕刷新或延时。
- 比赛态尽量关闭 VOFA 和速度测试打印。
- 菜单适合停车或预启动时使用，运行态不应依赖菜单刷新完成控制。
