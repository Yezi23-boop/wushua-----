# 运行与排障

## 赛前检查

上车前建议至少确认这些项目：

1. 供电正常，低压保护不会误触发
2. 电感四路采样有响应，`Err` 不异常
3. 编码器读数正常，左右轮方向对应正确
4. IMU 更新正常，角速度和姿态没有明显卡死
5. 起跑状态和负压状态逻辑符合当前场景
6. 当前需要的参数已经 `SAVE`
7. 比赛态下不打开多余调试输出

## 启动异常

### 上电后车不动

优先排查：

1. `flat_statr` 是否推进到允许输出的状态
2. `stop` 是否被保护逻辑拉起
3. 电机 PWM 初始化是否成功
4. 起跑输入条件是否满足

### 改了参数却感觉没变化

优先排查：

1. 改的是配置型参数还是运行型参数
2. 是否走了 `control_apply_config()`
3. 是否误以为必须重启才生效

## 丢线相关

如果车在高速下突然发散或迟滞：

1. 先看四路电感是否正常
2. 再看 `Err` 是否连续、是否突然归零
3. 再看 `lost_lines()` 是否误触发保护
4. 再看转向环是否对大误差过猛或过钝

## 低压相关

如果车偶发突然停：

1. 检查供电是否真实下降
2. 检查 `dianya_jiance()` 的计数行为
3. 分辨是低压停机还是丢线停机

## 负压异常

如果负压效果不明显或介入时机不对：

1. 看 `flat_statr` 和 `start_flag`
2. 看姿态数据是否连续
3. 看 `phase` 是否正确切换
4. 看最终输出是否真的使用了当前计算值

## 菜单与 VOFA 异常

### 菜单卡顿

当前菜单实现偏调试态，包含阻塞式页面循环和打印，适合调车，不适合比赛常开。

### VOFA 命令无响应

优先排查：

1. 当前主循环是否启用了 VOFA 服务入口
2. 无线串口和 FIFO 是否正常
3. 命令是否以 `!` 结尾
4. 命令是否属于当前实现真正支持的集合

## 排障建议顺序

出现问题时，建议按这条顺序判断：

1. 硬件是否正常
2. 传感器是否正常
3. 状态机是否正常
4. 参数是否合理
5. 控制器是否同步
6. 调试工具是否误导了观察结果
