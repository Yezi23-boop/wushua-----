# 跷跷板停止等待模式测试指南

## 测试目标

验证跷跷板停止等待模式功能正常，包括菜单切换、EEPROM 存储、两种模式行为。

## 测试前准备

1. 确保小车硬件正常
2. 确保赛道包含跷跷板元素
3. 确保 EEPROM 已初始化（首次上电会自动初始化）

## 测试用例

### 测试 1: 菜单切换

**目标**：验证 seesaw_mode 菜单项可正常切换

**步骤**：
1. 进入菜单系统
2. 导航到 FLY 页面（飞坡参数页面）
3. 找到 "seesaw_mode" 菜单项
4. 按 K1 切换到 1（停止等待模式）
5. 按 K2 切换回 0（飞坡模式）

**预期结果**：
- 菜单项显示 "seesaw_mode: 0" 或 "seesaw_mode: 1"
- 按 K1/K2 可正常切换
- 切换后立即生效

### 测试 2: EEPROM 存储

**目标**：验证 seesaw_mode 参数可正确保存到 EEPROM

**步骤**：
1. 进入菜单系统
2. 在 FLY 页面设置 seesaw_mode = 1
3. 在菜单首页按 K4 保存
4. 重启系统
5. 进入菜单查看 seesaw_mode 值

**预期结果**：
- 保存后 seesaw_mode 保持为 1
- 重启后 seesaw_mode 仍为 1

### 测试 3: 飞坡模式行为

**目标**：验证 seesaw_mode = 0 时，跷跷板行为与原来相同

**步骤**：
1. 设置 seesaw_mode = 0
2. 配置元素序列包含跷跷板（如：1,5,7,6）
3. 在包含跷跷板的赛道上运行
4. 观察小车行为

**预期结果**：
- 检测到弱磁后继续前进飞过跷跷板
- 行为与原来完全相同

### 测试 4: 停止等待模式行为

**目标**：验证 seesaw_mode = 1 时，停止等待模式正常工作

**步骤**：
1. 设置 seesaw_mode = 1
2. 配置元素序列包含跷跷板（如：1,5,7,6）
3. 在包含跷跷板的赛道上运行
4. 观察小车行为

**预期结果**：
- 检测到弱磁后停车
- 等待约 1 秒
- 电感信号恢复后出发
- 阶梯增速恢复到巡线速度
- 完成后正确推进到下一个元素

### 测试 5: 元素序列推进

**目标**：验证跷跷板完成后正确推进到下一个元素

**步骤**：
1. 配置元素序列：1,5,7,6（左圆环、圆桶、跷跷板、墙面）
2. 运行完整序列
3. 观察元素切换顺序

**预期结果**：
- 左圆环 → 圆桶 → 跷跷板 → 墙面 → 循环
- 每个元素完成后正确切换到下一个

## 调参建议

如果停止等待模式行为不理想，可调整以下参数：

### 等待时间
当前固定为 1 秒（500 * 2ms）。如果需要调整，修改 `a_run_fly.c` 中的：
```c
if (seesaw_wait_count >= 500)  /* 500 * 2ms = 1000ms */
```

### 倾斜确认阈值
当前使用与飞坡相同的阈值。如果需要调整，修改 `a_run_fly.c` 中的：
```c
if (ad1 > FLY_LANDING_SIDE_TH &&
    ad4 > FLY_LANDING_SIDE_TH &&
    ad2 > FLY_LANDING_CENTER_TH &&
    ad3 > FLY_LANDING_CENTER_TH)
```

## 故障排除

### 问题 1: 菜单项不显示
- 检查 `menu_have_sub[]` 是否包含 64
- 检查 `Menu_Fly_Process` 是否处理 case 64

### 问题 2: 模式切换不生效
- 检查 `app.fly.seesaw_mode` 是否正确读取
- 检查 `a_run_track_element.c` 中是否正确判断 `seesaw_mode`

### 问题 3: 停车后不出发
- 检查电感信号是否恢复（ad1/ad4 > 15，ad2/ad3 > 10）
- 检查等待时间是否足够（1 秒）

### 问题 4: 速度恢复不平滑
- 检查 `a_run_fly_update_release_speed()` 是否正常执行
- 检查 `flat_fly` 是否设置为 `FLY_STATE_COOLDOWN`
