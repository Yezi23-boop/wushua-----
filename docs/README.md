# 项目知识库

这套知识库服务两个目标：

- 方便当前项目继续调车、排障和现场改参
- 方便后续接手者快速理解代码结构、控制链路和参数流转

文档内容以当前仓库代码真实行为为准，重点覆盖 `project/user` 与 `project/service` 下的自研模块。第三方库和底层平台只做依赖说明，不在第一版中逐文件展开。

## 目录结构

- `01-项目总览`：项目背景、平台、硬件和软件主链
- `02-系统架构`：启动流程、定时器任务、参数流转和职责边界
- `03-模块说明`：核心自研模块说明
- `04-调参与策略`：参数含义、调参顺序、VOFA 与菜单关系
- `05-运行与排障`：赛前检查和常见异常排查
- `06-参考资料`：参数表、全局状态表、术语表
- `07-已知问题与优化`：已识别风险和后续优化方向

## 维护约定

- 文档以中文编写，编码使用 UTF-8
- 以当前实现为准，不机械照抄旧注释或历史文档
- 模块文档统一回答这些问题：
  - 这个模块做什么
  - 对外入口是什么
  - 它依赖谁、被谁依赖
  - 关键状态和配置有哪些
  - 高频路径有什么实时性注意点
  - 调参与常见风险是什么
