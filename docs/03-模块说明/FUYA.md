# FUYA 模块

## 模块职责

`FUYA.c` 负责负压系统控制，根据当前姿态和场景估计结果调整负压输出。

## 对外入口函数

- `fuya_Init()`
- `fuya_motor_output(int pwm)`
- `fuya_update_simple()`

## 依赖与被依赖关系

依赖：

- `vx / vy / vz`
- `app.start.fuya_xili`
- 启停状态和起跑状态

被依赖：

- `int_user.c`
- `a_run_mode.c`

## 关键运行数据

- `fuya_date`
- `fuya_date_factor`
- `phase`

## 高频路径注意事项

- 负压控制位于业务策略链，不应加入大量调试输出
- 场景识别和占空比计算应尽量保持简单可预测
- 若后续继续优化该模块，优先确认“实际输出值”是否与“计算值”一致

## 调参与常见风险

- 当前对外暴露的主要可调参数是 `fuya_xili`
- 如果壁面和立体桶场景附着异常，先检查姿态更新和 `phase` 判断
- 如果调参对实际输出影响不明显，先确认最终输出是否真的使用了计算结果
