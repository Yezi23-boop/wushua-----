# a_run 模块

## 模块职责

`a_run.c` 是定时任务主链，负责把采样、控制器更新和电机输出串成稳定的实时循环。

## 对外入口函数

- `run_time_1()`
- `run_time_2()`
- `run_time_3()`

## 依赖与被依赖关系

依赖：

- `ADC`
- `imu`
- `pid`
- `motor`
- `a_run_mode`

被依赖：

- `isr.c`

## 关键运行数据

- `flat_statr`
- `flat_fly`
- `speed_active`

## 高频路径注意事项

- `run_time_1()` 是最关键的实时控制路径
- `run_time_2()` 负责监测与状态更新，频率相对低一些
- `run_time_3()` 当前未挂接到中断主链，若重新启用必须先确认不会与现有控制链冲突

## 运行逻辑概览

`run_time_1()` 的核心顺序是：

1. IAP 保护处理
2. 电感采样
3. 数据准备
4. 编码器读取
5. 转向环
6. 飞坡速度策略
7. 角度环
8. 速度环
9. 电机输出

`run_time_2()` 的核心顺序是：

1. 扫描最大值
2. 丢线检测
3. 电压检测
4. 姿态更新
5. 起跑状态更新
6. 负压状态更新

## 调参与常见风险

- 如果车辆表现为“能跑，但偶发慢半拍”，优先怀疑高频链里数据更新顺序
- 如果改了参数却感觉没有立即生效，要确认修改路径是否经过 `control_apply_config()`
- 如果比赛态需要极限性能，尽量不要往 `run_time_1()` 再加调试输出
