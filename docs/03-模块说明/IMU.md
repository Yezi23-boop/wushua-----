# IMU 模块

## 模块职责

`imu.c` 负责 IMU 数据准备、偏置相关处理和姿态更新支撑，给圆环角速度环、转角积分、赛道元素判断和姿态显示提供基础数据；普通巡线误差环不使用 gyro_z。

## 对外入口函数

- `offset_init()`：上电初始化后做偏置准备
- `Prepare_Data()`：为控制链准备传感器数据
- `IMUupdate()`：更新姿态相关数据结构

## 依赖与被依赖关系

依赖：

- IMU 硬件驱动
- 滤波模块

被依赖：

- `int_user.c` 的业务初始化
- `a_run.c` 的周期任务
- `FUYA.c` 的场景判断与负压控制
- 调试显示和菜单

## 关键运行数据

- `gyro_z`：角速度相关实时值
- `Gyr_filt`
- `Acc_filt`
- `Att_Angle`
- `vx / vy / vz`

## 高频路径注意事项

- IMU 相关数据同时服务控制和姿态判断，必须注意跨中断共享状态的一致性
- 偏置和滤波越复杂，越可能拖慢姿态更新，调车时应优先保证角速度可用性
- 比赛态下不建议把 IMU 调试打印放进高频路径

## 调参与常见风险

- 如果角度环表现异常，先分辨是 IMU 数据问题还是控制参数问题
- 如果负压相位切换不稳定，先看 `vx / vy / vz` 和姿态更新是否连续
- 如果刚上电姿态明显漂移，要先检查偏置初始化时机
