# ADC 模块

## 模块职责

`ADC.c` 负责四路电感的采样、滤波、归一化和位置误差 `Err` 计算，是循迹控制链最前端的数据来源。

## 对外入口函数

- `read_AD()`：读取四路电感并更新 `ad1~ad4` 与 `Err`
- `scan_track_max_value()`：更新四路采样的历史最大值

## 依赖与被依赖关系

依赖：

- ADC 硬件接口
- `app.angle.A_1 / B_1 / C_l`

被依赖：

- `a_run.c` 的 `run_time_1()` 和 `run_time_2()`
- `pid.c` 中的转向控制
- 菜单、VOFA 或调试显示读取实时值

## 关键运行数据

- `RAW[4]`：四路原始采样
- `MA[4]`：最大值参考
- `ad1~ad4`：归一化后的电感值
- `Err`：电感计算出的横向误差

## 高频路径注意事项

- 该模块位于实时控制主链中，必须尽量避免重运算和多余拷贝
- 当前误差计算已增加分母保护，避免在弱信号或丢线时产生异常值
- 如果后续再加滤波，必须控制好延迟，避免高速状态下转向变钝

## 调参与常见风险

核心相关参数：

- `A_1`
- `B_1`
- `C_l`

它们影响误差曲线的比例和非线性区间，调参时建议与转向环参数联动观察。  
如果车在直线稳定、弯道却突然发飘，先确认误差计算是否仍然连续，再去动 PID。
