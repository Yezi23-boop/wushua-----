# Menu 模块

## 模块职责

`menu.c` 提供屏幕菜单显示、参数查看和现场改参入口，是离线调参的主要交互方式。

## 对外入口函数

- `Keystroke_Menu()`

以及一组内部页面函数和按键编辑函数，例如：

- `Keystroke_float()`
- `Keystroke_int()`
- `Keystroke_Special_Value()`

## 依赖与被依赖关系

依赖：

- 屏幕驱动
- 按键输入
- `g_app_config`
- `config_save()`
- 控制器实时值和传感器实时值

被依赖：

- `main.c`

## 关键运行数据

- `menu_next_flag`
- 当前页面索引
- 当前编辑目标参数

## 高频路径注意事项

- 菜单运行在主循环，不在定时中断主链
- 当前菜单实现包含阻塞式页面循环和调试打印，适合调车，不适合比赛态常开
- 菜单改参后会调用统一配置应用路径，参数可以立即生效

## 调参与常见风险

- 菜单退出保存依赖 `config_save()`，不要绕开这条路径
- 如果界面显示和实际跑车表现不一致，先确认读取的是配置值还是实时值
- 如果比赛态不需要菜单，建议在主循环里关闭对应编译开关
