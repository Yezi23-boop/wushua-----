# Motor 模块

## 模块职责

`motor.c` 负责左右电机 PWM 输出，以及丢线和低压等保护逻辑。

## 对外入口函数

- `motor_Init()`
- `motor_output(int lpwm, int rpwm)`
- `lost_lines()`
- `dianya_jiance()`
- `motor_speed_to_duty()`

## 依赖与被依赖关系

依赖：

- PWM 硬件接口
- 电压检测输入
- 电感状态

被依赖：

- `int_user.c` 的硬件初始化
- `a_run.c` 的控制主链
- `vofa.c` 的启停测试

## 关键运行数据

- `stop`：停车保护标志
- `dianya`：电压相关值

## 高频路径注意事项

- `motor_output()` 在高频控制链中执行，逻辑应尽量简单、可预测
- 保护逻辑触发后对控制结果影响很直接，必须明确“是滑行、抱死还是轻制动”
- 电机输出函数中的左右轮参数命名和实际映射需要保持清晰，否则很容易误调

## 调参与常见风险

- 当前保护计数逻辑更偏累计触发，后续如果发现“偶发后突然停”，优先检查保护计数是否有恢复清零机制
- 若停车后仍感觉有推力，先确认 `stop` 分支输出策略
- 若左、右轮调参直觉与实际表现相反，先检查参数命名与物理接线是否一致
