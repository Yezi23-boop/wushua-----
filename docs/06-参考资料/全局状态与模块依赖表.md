# 全局状态与模块依赖表

## 关键全局状态

| 名称         | 所属模块 | 作用                         |
| ------------ | -------- | ---------------------------- |
| `app`        | `eeprom` | 全局配置真值                 |
| `PID`        | `pid`    | 当前运行中的控制器参数与状态 |
| `Err`        | `ADC`    | 电感误差                     |
| `ad1~ad4`    | `ADC`    | 四路电感处理值               |
| `gyro_z`     | `imu`    | 角速度相关值                 |
| `Att_Angle`  | `imu`    | 姿态相关结构                 |
| `current_start_state` | `a_run_mode` | 起停状态：0-停止，1-预启动，2-运行 |
| `expected_element` | `a_run_track_element` | 当前开放的赛道元素识别阶段 |
| `ring_data` | `a_run_track_element` | 圆环过程状态、里程和角度积分 |
| `flat_fly`   | `a_run_fly` | 飞坡/跷跷板阶段标志          |
| `fly_lost_line_blocked` | `a_run_fly` | 飞坡高风险窗口丢线屏蔽标志 |
| `stop`       | `motor`  | 停车保护标志                 |
| `dianya`     | `motor`  | 电压相关值                   |
| `fuya_date`  | `FUYA`   | 负压计算结果                 |
| `phase`      | `FUYA`   | 负压场景相位                 |

## 模块依赖关系

| 模块         | 主要依赖                                        | 主要被谁调用              |
| ------------ | ----------------------------------------------- | ------------------------- |
| `main`       | `int_user` `menu` `vofa` `debug_view`           | 系统入口                  |
| `int_user`   | `eeprom` `imu` `pid` `motor` `FUYA`             | `main`                    |
| `isr`        | `a_run`                                         | 硬件中断                  |
| `a_run`      | `ADC` `imu` `pid` `motor` `a_run_mode` `a_run_track_element` `a_run_fly` | `isr` |
| `a_run_mode` | `FUYA` `a_run_track_element`                    | `a_run` `menu`            |
| `a_run_track_element` | `ADC` `imu` `FUYA` `a_run_fly` `app`   | `a_run` `a_run_mode`      |
| `a_run_fly`  | `ADC` `pid` `app`                               | `a_run` `a_run_track_element` `motor` |
| `ADC`        | ADC 硬件 `app`                                  | `a_run`                   |
| `imu`        | IMU 硬件 `filter`                               | `int_user` `a_run` `FUYA` |
| `pid`        | `imu` `ADC` 编码器 `app`                        | `int_user` `a_run` `vofa` |
| `motor`      | PWM 硬件 电压采样                               | `int_user` `a_run`        |
| `menu`       | 屏幕 按键 `app`                                 | `main`                    |
| `vofa`       | 无线串口 `app`                                  | `main`                    |
| `eeprom`     | IAP/EEPROM 接口                                 | 多模块                    |
| `FUYA`       | 姿态数据 `app`                                  | `int_user` `a_run_mode` `a_run_track_element` |

## 依赖管理建议

- 配置类参数优先归 `app`
- 高频运行态尽量避免无意义暴露
- 跨中断共享的状态应保持命名清晰、语义稳定
