# 全局状态与模块依赖表

## 关键全局状态

| 名称 | 所属模块 | 作用 |
| --- | --- | --- |
| `g_app_config` | `eeprom` | 全局配置真值 |
| `PID` | `pid` | 当前运行中的控制器参数与状态 |
| `Err` | `ADC` | 电感误差 |
| `ad1~ad4` | `ADC` | 四路电感处理值 |
| `gyro_z` | `imu` | 角速度相关值 |
| `Att_Angle` | `imu` | 姿态相关结构 |
| `flat_statr` | `a_run` | 起跑状态 |
| `flat_fly` | `a_run` | 飞坡阶段标志 |
| `stop` | `motor` | 停车保护标志 |
| `dianya` | `motor` | 电压相关值 |
| `fuya_date` | `FUYA` | 负压计算结果 |
| `phase` | `FUYA` | 负压场景相位 |

## 模块依赖关系

| 模块 | 主要依赖 | 主要被谁调用 |
| --- | --- | --- |
| `main` | `int_user` `menu` `vofa` `debug_view` | 系统入口 |
| `int_user` | `eeprom` `imu` `pid` `motor` `FUYA` | `main` |
| `isr` | `a_run` | 硬件中断 |
| `a_run` | `ADC` `imu` `pid` `motor` `a_run_mode` | `isr` |
| `a_run_mode` | `FUYA` `eeprom` | `a_run` |
| `ADC` | ADC 硬件 `g_app_config` | `a_run` |
| `imu` | IMU 硬件 `filter` | `int_user` `a_run` `FUYA` |
| `pid` | `imu` `ADC` 编码器 `g_app_config` | `int_user` `a_run` `vofa` |
| `motor` | PWM 硬件 电压采样 | `int_user` `a_run` |
| `menu` | 屏幕 按键 `g_app_config` | `main` |
| `vofa` | 无线串口 `g_app_config` | `main` |
| `eeprom` | IAP/EEPROM 接口 | 多模块 |
| `FUYA` | 姿态数据 `g_app_config` | `int_user` `a_run_mode` |

## 依赖管理建议

- 配置类参数优先归 `g_app_config`
- 高频运行态尽量避免无意义暴露
- 跨中断共享的状态应保持命名清晰、语义稳定
