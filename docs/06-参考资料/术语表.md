# 术语表

| 术语         | 含义                                                            |
| ------------ | --------------------------------------------------------------- |
| 电感四路     | 用于检测电磁线的四个传感器通道                                  |
| `Err`        | 根据四路电感计算出的循迹横向误差                                |
| 速度环       | 控制左右轮速度的闭环                                            |
| 转向环       | 根据电感误差生成姿态或转向目标的闭环                            |
| 角度环       | 根据转向目标和角速度生成差速控制量的闭环                        |
| `app`        | 当前统一的配置结构体                                            |
| `PID`        | 当前运行中的控制器对象                                          |
| `SAVE`       | 将当前配置写入 EEPROM                                           |
| `LOAD`       | 从 EEPROM 恢复配置并重新应用                                    |
| `current_start_state` | 起停状态：0-停止，1-预启动，2-运行                     |
| `expected_element` | 当前赛道元素仲裁阶段，用于决定开放哪类元素识别             |
| `flat_fly`   | 飞坡/跷跷板状态机阶段                                           |
| `fly_lost_line_blocked` | 飞坡高风险窗口中的丢线保护屏蔽标志                  |
| 飞坡         | 车辆经过飞坡或坡道类元素时的专门策略                            |
| 跷跷板       | 当前由 `a_run_fly` 处理的弱磁、离线保持和落地恢复类元素          |
| 圆桶         | 当前由 `a_run_track_element` 处理的强信号、回地和稳定延时元素    |
| 负压         | 用于壁面或特殊路段附着的负压系统                                |
| FireWater    | VOFA 中常用的 ASCII 文本帧风格，当前项目以 `!` 作为命令结束标记 |
