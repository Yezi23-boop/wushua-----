## 实现步骤

### 1. a_run_track_element.h — 新增元素编号

```c
#define TRACK_ELEMENT_CROSS 6        /**< 双十字流程显示值。 */
```

### 2. eeprom.h — 新增 AppCrossConfig

```c
typedef struct
{
    float encoder_target; /**< 双十字退出编码器积分阈值 */
} AppCrossConfig;
```

在 `AppConfig` 中加 `AppCrossConfig cross;`

### 3. eeprom.c — 默认值 + 读写

- 默认：`config->cross.encoder_target = 20.0f;`
- 读取：`config->cross.encoder_target = read_float(56);`
- 校验：`<= 0` 时回退默认值
- 保存：`save_float(config->cross.encoder_target, 56);`

### 4. a_run_cross.h — 新建

```c
#ifndef __A_RUN_CROSS_H__
#define __A_RUN_CROSS_H__
#include "a_run_track_element.h"

void a_run_cross_reset(void);
uint8 a_run_cross_update_5ms(void);
int8 a_run_cross_get_state(void);

#endif
```

### 5. a_run_cross.c — 新建状态机

三阶段：CROSS_IDLE → CROSS_WAIT_SIGNAL → CROSS_TIMING

- **IDLE**：清零内部状态，立即切到 WAIT_SIGNAL
- **WAIT_SIGNAL**：`ad1+ad2+ad3+ad4 > 100` 连续命中 2 次后进 TIMING
- **TIMING**：编码器积分 `(speed_l + speed_r) * 0.5 * 0.012`，达到 `app.cross.encoder_target` 后 reset 并返回 1

不覆盖 speed，不覆盖 angle_target。

### 6. a_run_track_element.c — 接入

- 枚举加 `ELEMENT_CROSS = TRACK_ELEMENT_CROSS`
- `track_element_is_executable()` 加 `element == ELEMENT_CROSS`
- `track_element_enter()` 加 `a_run_cross_reset()`
- switch 加 `case ELEMENT_CROSS`

### 7. menu.c — YUANSHU 页 + CROSS 子页

- YUANSHU 页加第 5 行 "CROSS" + 状态显示
- cursor max 从 4 改 5
- 新增 case 45（导航）和 case 451（编辑 encoder_target）
- CROSS 子页只显示 1 个参数：encoder_target
