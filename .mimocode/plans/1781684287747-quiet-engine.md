# 拆分飞坡/停止等待模式的共享常量和菜单参数

## 目标

将飞坡模式和停止等待模式共用的 #define 常量和 app.fly 菜单参数完全分离，使两个模式各自独立可调。

## 修改文件

1. `project/user/a_run_fly.c` — 常量拆分 + 代码引用更新
2. `project/service/eeprom.h` — AppFlyConfig 结构体重构
3. `project/service/eeprom.c` — 默认值 + EEPROM 读写（槽位兼容）
4. `project/service/menu.c` — 按 seesaw_mode 切换显示参数

## 一、常量拆分（a_run_fly.c）

删除旧常量，替换为：

```c
/* 飞坡模式专用 */
#define FLY_DETECT_SIDE_TH 25u
#define FLY_DETECT_CENTER_TH 10u
#define FLY_LAND_SIDE_TH 20u
#define FLY_LAND_CENTER_TH 10u

/* 停止等待模式专用 */
#define SEESAW_DETECT_SIDE_TH 25u
#define SEESAW_DETECT_CENTER_TH 10u
#define SEESAW_LAND_SIDE_TH 20u
#define SEESAW_LAND_CENTER_TH 10u
```

## 二、AppFlyConfig 重构（eeprom.h）

```c
typedef struct
{
    /* 飞坡模式专用 */
    int fly_speed;           /* LOW 阶段目标速度 */
    int fly_detect_count;    /* IDLE 入口弱磁确认次数 */
    int fly_airborne_th;     /* 离地检测阈值（四路全部 ≤ 该值） */
    /* 停止等待模式专用 */
    int seesaw_detect_count; /* IDLE 入口命中次数 */
    int seesaw_wait_count;   /* 停车等待时间（×2ms） */
    int seesaw_speed;        /* CREEP 阶段目标速度 */
    float seesaw_creep_cm;   /* 前挪距离（cm） */
    /* 共用 */
    int16 seesaw_mode;       /* 0=飞坡，1=停止等待 */
    int recover_speed;       /* COOLDOWN 恢复速度 */
    float release_step;      /* COOLDOWN 步长 */
} AppFlyConfig;
```

## 三、EEPROM 槽位映射（eeprom.c）

| 23 | count_fly_time_1 (int) | fly_detect_count (int) |
| 24 | count_fly_time_2 (int) | seesaw_detect_count (int) |
| 25 | seesaw_mode (int16) | seesaw_mode (int16) |
| 37 | seesaw_wait_count (int) | seesaw_wait_count (int) |
| 38 | recover_speed (int) | recover_speed (int) |
| 39 | release_step (float) | release_step (float) |
| 40 | seesaw_creep_cm (float) | seesaw_creep_cm (float) |
| **52** | (新增) | fly_airborne_th (int) |
| **53** | (新增) | seesaw_speed (int) |

## 五、菜单（menu.c）

当前飞坡子页面（Fly_Sub）显示 7 行参数。改为按 seesaw_mode 切换：

**Row 0**: seesaw_mode（模式选择，两种模式都显示）

**当 seesaw_mode == 0（飞坡）**：
- Row 1: fly_speed
- Row 2: fly_detect_count
- Row 3: fly_airborne_th
- Row 4: recover_speed
- Row 5: release_step
- Row 6: (空或调试信息)

**当 seesaw_mode == 1（停止等待）**：
- Row 1: seesaw_speed
- Row 2: seesaw_detect_count
- Row 3: seesaw_wait_count
- Row 4: seesaw_creep_cm
- Row 5: recover_speed
- Row 6: release_step

光标最大行根据模式动态调整（飞坡 5 行，停止等待 6 行）。

编辑 case 也要按模式映射到不同参数。
