# 跷跷板 ADC 居中权重生效起点改为 COOLDOWN

## 目标

将 `seesaw_centering_active` 的生效起点从 CREEP（前挪阶段）推迟到 COOLDOWN（阶梯增速阶段），使 CREEP 和 RECOVER 阶段使用菜单中的全局 ABC 权重循迹。

## 修改文件

`project/user/a_run_fly.c`

## 具体改动

### 1. SEESAW_BRAKE → CREEP 转换（line 230-233）

当前：
```c
if (creep_target > 0.0f)
{
    seesaw_centering_active = 1;
    seesaw_state = SEESAW_CREEP;
}
```

改为：
```c
if (creep_target > 0.0f)
{
    seesaw_centering_active = 0;
    seesaw_state = SEESAW_CREEP;
}
```

### 2. SEESAW_CREEP 每周期（line 251）

当前：
```c
seesaw_centering_active = 1;
```

删除该行。

### 3. SEESAW_RECOVER 入口（line 295）

当前：
```c
seesaw_centering_active = 1;
```

删除该行。

### 4. COOLDOWN（a_run_fly_update_release_speed line 325）— 不变

```c
seesaw_centering_active = 1;
```
保留。

## 状态机各阶段 ADC 权重变化总结

| 阶段 | 改动前 | 改动后 |
|------|--------|--------|
| IDLE | 全局 ABC | 全局 ABC |
| BRAKE | 全局 ABC | 全局 ABC |
| CREEP | 居中 ABC | 全局 ABC |
| STOP | 全局 ABC | 全局 ABC |
| WAIT | 全局 ABC | 全局 ABC |
| CHECK | 全局 ABC | 全局 ABC |
| RECOVER | 居中 ABC | 全局 ABC |
| COOLDOWN | 居中 ABC | 居中 ABC |
