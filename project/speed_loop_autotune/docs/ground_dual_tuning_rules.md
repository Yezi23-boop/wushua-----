# Ground Dual Speed Loop Tuning Rules

这份文档只记录带负载双轮 `ground-dual` 的默认流程与判断习惯。
它和架空双轮 `air-dual` 分开维护，避免把两种试验条件下的经验混在一起。

## 目标

- 目标是验证带负载双轮在真实阻力与供电压降下是否还能稳定跑完预设序列。
- 重点不是单段最低分，而是整组试验的可重复性、停车质量和残余输出。

## 默认调试环境

- 端口：`COM8`
- 模式：`ground-dual`
- 负压：按实车/带载需求设置，不默认沿用架空 `AT_FUYA=0`
- 保存：默认不发送 `SAVE`

## 默认试验序列

当前代码内置的带负载双轮序列为：

- `25:200,35:200,45:200,35:200,25:200`

这是带负载双轮当前的默认回归模板，对应代码里的 `build_ground_load_trials()`。

## 默认命令链

带负载双轮应优先使用以下链路：

1. `AT_FUYA=<value>`
2. `AT_COOLDOWN_MS=<value>`
3. `AT_ARM`
4. `AT_TRIAL_MS=<value>`
5. `AT_SPEED=<first_target>`
6. `AT_FIRE`

说明：

- `AT_ARM` 负责进入带负载试验待发状态
- `AT_FIRE` 才是真正拉起试验
- `AT_COOLDOWN_MS` 用于控制停车后的冷却窗口

## 默认评分关注点

带负载双轮默认更关心：

- 每个速度段的综合得分
- 试验结束时 `stop_flag` 是否正常
- 结束时 `trial_active` 是否已经拉低
- 冷却段残余速度是否回零
- 残余 PWM 是否过大

## 当前经验边界

- 带负载双轮的评分逻辑和架空双轮不同，不能直接照搬 `air-dual` 的结论
- `air-dual` 里的单轮隔离经验，只能作为初筛参考，不能直接当作带负载默认值
- 如果参数只在架空双轮有效、但在带负载双轮出现高 PWM 低车速，应优先以带负载结果为准

## 当前推荐流程

1. 先用 `air-dual` 找到左右轮可用区间
2. 再切到 `ground-dual` 做整组带负载双轮回归
3. 如果带负载结果明显变差，不要继续放大搜索，优先回退到更保守组合
4. 带负载新经验写入 `ground_dual_debug_memory.md`

## 文档更新规则

- 架空双轮经验不要写进本文件
- 只记录带负载双轮下重复验证过的规则
- 如果将来形成稳定实车/带载默认值，再升级回专题 README
